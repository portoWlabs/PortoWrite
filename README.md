# portoWrite

Cross-platform authoring tool for fiction writers and self-publishers. Live multi-device ebook preview, EPUB 3.3 export, footnotes, track changes — from one offline desktop app.

## Download

See the [Releases page](https://github.com/portoWlabs/PortoWrite/releases) for the latest installer.

Currently shipping: Windows. macOS and Linux builds coming.

## Editions

**Free** — core writing surface, EPUB export, themes, 3 device profiles, focus mode, find/replace, autosave, spell-check.

**Pro — $49 one-time** — full 15-device emulation, DOCX with track-changes round-trip, footnotes/endnotes, hyperlinks, EPUB validation, KDP/IngramSpark templates, commercial-use license.

Purchase: [ko-fi.com/portowlabs](https://ko-fi.com/portowlabs)
